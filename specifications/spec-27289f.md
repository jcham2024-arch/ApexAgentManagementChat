   missing.

**.agents/rules/context-discipline.md**
```markdown
# Context Discipline

## Budgets
- Root `AGENTS.md`: 15–40 lines. It is a map, not a manual.
- Rule files: 10–30 lines each.
- Domain guides: under 300 lines.
- `SKILL.md`: under 500 lines. Split at 500.

## Principles
- Do not preload. Read just-in-time per the routing table.
- Every token is budget. Cut what does not earn its slot.
- Push state outside the window. Large tool outputs go to `scratch/`.
- If a file exceeds its budget, split or prune — do not compress prose
  to fit.
- When a task repeats the same failure twice, add one line to the
  matching rule file. Do not add a new file.
```

**.agents/rules/file-placement.md**
```markdown
# File Placement

| Folder | Holds | Mutability |
|---|---|---|
| `00_context/` | goal anchor, scope, non-negotiables | read-only after stage 0 |
| `01_research/` | findings, source notes, unknowns | append-only |
| `02_design/` | proposals, tradeoffs, diagrams | editable until gate 2 |
| `03_execute/` | code, build scripts, configs | only place code lives |
| `04_verify/` | test results, review notes | append-only |
| `reference/` | glossary, API notes, durable facts | editable |
| `scratch/` | disposable work, tool dumps | never cited in output |
| `review/` | items awaiting human sign-off | human clears |
| `output/` | approved, shippable artifacts | write once at gate 4 |

Never write outside these folders. If a file does not fit, create a new
stage folder rather than polluting an existing one.
```

**.agents/rules/review-gates.md**
```markdown
# Review Gates

No stage advances without its gate. The agent stops and reports.

## Gate 1 — Research to Design
- Every claim has a source or is marked `[unverified]`.
- Unknowns are listed explicitly.
- `01_research/CONTEXT.md` is complete.

## Gate 2 — Design to Execute
- One approach is chosen; alternatives are noted with why rejected.
- Blast radius is stated: files touched, tests affected.
- `02_design/CONTEXT.md` is complete.

## Gate 3 — Execute to Verify
- Code compiles and tests are written.
- No placeholder bodies (`return null`, `TODO`).
- `03_execute/CONTEXT.md` is complete.

## Gate 4 — Verify to Output
- All tests pass. Lint passes.
- Human has signed off in `review/`.
- Artifact is copied to `output/` and the stage is closed.
```

**.agents/skills/research/SKILL.md**
```markdown
---
name: research
description: Use when the task requires gathering facts, sources, or unknowns before a design decision.
---

# Research

## Inputs
- The goal from `00_context/goal.md`.
- The research context from `01_research/CONTEXT.md`.

## Process
1. List what is known vs. unknown. Write it to `01_research/notes.md`.
2. For each unknown, gather evidence. Cite source and date.
3. Mark anything unverifiable as `[unverified]`.
4. Summarize findings in `01_research/findings.md`.

## Outputs
- `01_research/findings.md` — one page, bulleted, sourced.
- `01_research/unknowns.md` — explicit gaps.

## Gate
Stop. Present findings and unknowns. Do not design until approved.
```

# Design

## Inputs
- `01_research/findings.md`, `01_research/unknowns.md`.
- `00_context/goal.md`.

## Process
1. Write at least two candidate approaches to `02_design/proposal.md`.

- `02_design/proposal.md` — chosen approach, tradeoffs, file list.

## Gate
