# Apex Agent Management Chat

Enterprise-grade, self-evolving multi-agent platform. Java 21
microkernel plus a Content-Addressable Storage evolution plane.
Tauri 2.0 + React 19 client.

## Status
Pre-alpha. P1 not started. The workspace scaffolding is in place
(`AGENTS.md`, stages, rules, skills).

## Quick Start
- Read `AGENTS.md` first. It routes to the stage you need.
- Stage specs: `00_context/` through `04_verify/`.
- Rules: `.agents/rules/_index.md`.
- Skills: `.agents/skills/`.
