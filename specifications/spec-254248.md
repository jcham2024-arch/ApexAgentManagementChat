# Project Charter

## What
A self-evolving multi-agent platform. Agents propose changes on sandbox
branches; a six-category sentinel validates them; a human signs off;
the branch merges. The kernel is compiled Java and cannot be modified
at runtime.

## Who
Operators who need autonomous agents with auditable, reversible
self-improvement. Enterprise tenants with strict isolation requirements.

## Why
Autonomous agents fail dangerously when they can rewrite their own
behavior. Apex makes self-improvement a versioned, sandboxed, human-
reviewed operation — the same discipline Git + CI/CD brought to code.

## Constraints
- Java 21 LTS, no preview features (`ScopedValue` excluded).
- No dynamic bytecode. No shell interpolation.
- Every mutation is a CAS commit on a sandbox branch.
- Every merge requires a signed `PermissionGrant`.
- CI is the verifier; the agent cannot run Maven.
